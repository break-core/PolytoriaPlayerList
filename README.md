# Polytoria Player List Remake
This is a remake of the C# Player List code in Polytoria for Luau, so any game can run a custom player list if they want to

## Features
Almost every aspect of this code is customizable, whether you know what you're doing or not! It's recommended to check out [Config.luau](./PlayerList/Config.luau) for all customization options

I also added in some fun features like customizable names for those who care

## How to Install
Create a ClientScript in PlayerGUI called PlayerList and then put the rest of the modules under that. That is all you have to do to install the custom player list code

## Additional Notes
- This repository may become inaccurate to Polytoria's C# playerlist code over time if it's not maintained to be accurate
- There is a lot of missing documentation especially on Config options
